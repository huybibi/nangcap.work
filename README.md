# nangcap.work 🚀

Trang web chào mừng chính thức của **nangcap.work** — Nền tảng nâng tầm hiệu suất, tự động hoá và giải pháp công việc tương lai.

## ✨ Điểm Nổi Bật

- **Thiết kế hiện đại & Tối giản:** Tông màu Dark Slate, Glassmorphism, Responsive hoàn hảo trên mọi kích thước màn hình.
- **Trải nghiệm tương tác:** Lời chào cá nhân hoá theo khung giờ thực tế (sáng/trưa/tối), hiệu ứng icon Lucide mượt mà.
- **Tốc độ tải trang siêu nhanh:** Tối ưu hóa Static HTML, không phụ thuộc build phức tạp, sẵn sàng kích hoạt GitHub Pages.

## 🌐 Xem Trang Web Trực Tiếp

Bạn có thể kích hoạt **GitHub Pages** cho repository này tại:
- Cài đặt Repository: `Settings` > `Pages` > Nhánh: `main` / Thư mục: `/(root)`
- URL truy cập: `https://huybibi.github.io/nangcap.work/`
