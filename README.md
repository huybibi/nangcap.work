## ☁️ Deployment on Cloudflare Pages

The codebase is 100% static (HTML/CSS/JS with CDN assets). It deploys instantly on Cloudflare Pages:

### Method 1: Git Integration via Cloudflare Dashboard
1. Go to **Cloudflare Dashboard** > **Workers & Pages** > **Create application** > **Pages** > **Connect to Git**.
2. Select your private repository `nangcap.work`.
3. Set configuration:
   - **Framework preset:** `None`
   - **Build command:** *(leave empty)*
   - **Build output directory:** `/` (or `.`)
4. Click **Save and Deploy**. Cloudflare will auto-deploy on every push to `main`!

### Method 2: Deploy via Wrangler CLI
```bash
npx wrangler pages deploy . --project-name=nangcap-work
```
